COLLIE HANDYMAN SERVICES LLC — WEBSITE SETUP

This website uses FormSubmit.co to deliver quote requests without opening a visitor's email app. It works on GitHub Pages and the custom domain colliehandymanservices.com.

PUBLISH THE UPDATE
1. In GitHub, open: CollieHandymanServices/collie-handyman-services
2. Upload and replace every file from this folder, including thanks.html and the assets folder.
3. Commit the changes to the main branch.
4. Wait a few minutes, then visit https://colliehandymanservices.com.

ACTIVATE THE QUOTE FORM (ONE TIME ONLY)
1. On the published website, submit one complete test quote using an email address you can access.
2. Look in colliezach27@gmail.com for a message from FormSubmit.co. Check Spam/Junk if it is not in the Inbox.
3. Click the activation link in that message.
4. Submit another test quote. It should arrive directly in colliezach27@gmail.com, and visitors will see the website's thank-you page after submitting.

The activation email is a security step from FormSubmit. Until it is clicked, FormSubmit holds submitted requests and sends activation reminders. Do not change the form action or the hidden fields unless you want to change the quote email address or confirmation page.

Form fields collected: name, phone, email, project address/area, and project details.
