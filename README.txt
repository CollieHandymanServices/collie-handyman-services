FREE HOSTING: GITHUB PAGES
GitHub Pages can host this static website for free. A custom domain can also be connected.

QUICK SETUP
1. Create/sign into a GitHub account at https://github.com/
2. Create a NEW PUBLIC repository. A simple name is:
   collie-handyman-services
3. Upload index.html, style.css, script.js, and the entire assets folder.
4. In the repository, open Settings > Pages.
5. Under Build and deployment, choose "Deploy from a branch".
6. Choose the main branch and "/" (root), then Save.
7. GitHub will give you a github.io address.

CUSTOM DOMAIN
1. In GitHub: Settings > Pages > Custom domain, enter your domain and Save.
2. At the company where you bought the domain, update DNS.
3. For an apex domain (example.com), GitHub's current A records are:
   185.199.108.153
   185.199.109.153
   185.199.110.153
   185.199.111.153
4. For www.example.com, create a CNAME record named "www" pointing to:
   YOUR-USERNAME.github.io
   (replace YOUR-USERNAME with your GitHub username)
5. Return to GitHub Pages and turn on "Enforce HTTPS" after it becomes available.

IMPORTANT
DNS changes can take time to propagate. GitHub says this can take up to 24 hours.
Do not delete existing email-related MX records at your domain provider if you use the domain for email.
